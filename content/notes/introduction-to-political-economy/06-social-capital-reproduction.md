# 社会资本的再生产和流通

## 核心论点
- 本章要回答的核心问题：社会总产品如何在价值上和实物上得到补偿？社会资本简单再生产和扩大再生产的实现条件是什么？
- 作者的核心论证逻辑：
  1. 社会资本运动与个别资本运动的根本区别在于前者包含个人消费和一般商品流通
  2. 研究起点是社会总产品（社会总商品资本），核心问题是价值补偿和实物补偿的统一，即实现问题
  3. 马克思再生产理论的两个基本原理：社会总产品价值上分为c + v + m三部分，实物上分为生产资料和消费资料两大类，社会生产相应分为两大部类
  4. 简单再生产的基本实现条件：I(v+m) = IIc
  5. 扩大再生产的基本前提条件：I(v+m) > IIc；基本实现条件：I(v+Δv+m/x) = II(c+Δc)
  6. 在技术进步、资本有机构成提高的条件下，生产资料生产优先增长
  7. 资本主义内部矛盾（生产社会化与私人占有的矛盾、生产无限扩大趋势与消费有限性的矛盾）使实现条件经常遭到破坏，只能通过危机强制实现平衡

## 关键概念
- **[个别资本与社会资本](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：个别资本是各自独立发挥职能的资本，社会资本是互相联系、互相依存的个别资本的总和。社会资本的运动中包含着个人的消费以及与此相适应的简单商品流通，而个别资本运动则不包含这一过程。
- **[社会生产两大部类](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：第一部类（I）是生产资料的生产；第二部类（II）是消费资料的生产。这是马克思再生产理论的基本原理之一，是对社会生产最概括、最恰当的分类。
- **[社会总产品的实现](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：社会总产品各个部分在价值上和实物形态上都找到互相补偿的另一部分产品——实现问题即价值补偿和实物补偿的统一。在简单再生产下，I(v+m)必须等于IIc。
- **[简单再生产的实现条件](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：基本条件：I(v+m) = IIc。引申条件：I(c+v+m) = Ic + IIc（生产资料生产等于两大部类所消耗的生产资料）；II(c+v+m) = I(v+m) + II(v+m)（消费资料生产等于两大部类工资与剩余价值之和）。
- **[扩大再生产的实现条件](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：前提条件：I(v+m) > IIc。实现的基本条件：I(v+Δv+m/x) = II(c+Δc)。引申条件：（1）I(c+v+m) = Ic + IIc + IΔc + IIΔc；（2）II(c+v+m) = I(v+m/x) + II(v+m/x) + IΔv + IIΔv。
- **[生产资料生产优先增长](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：在资本有机构成提高的条件下，不变资本增长快于可变资本，因而生产资料生产增长快于消费资料生产。增长最快的是制造生产资料的生产资料生产，其次是制造消费资料的生产资料生产，最慢的是消费资料生产。但这不意味着生产资料生产可脱离消费资料生产而孤立发展。
- **["斯密教条"](https://liangkx.com/explore/introduction-to-political-economy/06-social-capital-reproduction)**：亚当·斯密的错误见解——将社会总产品价值仅分解为工资、利润和地租（v+m），排除了不变资本c。斯密不懂得劳动二重性，因而无法区分新价值创造和旧价值转移。这一"教条"使资产阶级经济学长期无法正确分析社会资本再生产。

## 研究证据
- 简单再生产图式：I. 4000c + 1000v + 1000m = 6000；II. 2000c + 500v + 500m = 3000。社会总产品价值9,000。
- 扩大再生产发端图式：I. 4000c + 1000v + 1000m = 6000；II. 1500c + 750v + 750m = 3000。第一部类积累50%，有机构成不变，逐年演进展示扩大过程。
- 魁奈《经济表》是研究社会资本再生产的第一次尝试，但有两个缺陷：未区分不变资本和可变资本、未划分两大部类。
- 俄国民粹派错误地认为剩余价值无法在国内实现因而资本主义在俄国不能发展——列宁批判指出小生产者破产恰恰扩大而非缩小国内市场。
- "合法马克思主义者"杜冈-巴拉诺夫斯基曲解实现论为证明资本主义可无危机发展——事实上马克思的实现论恰恰揭示了实现过程的内在矛盾。

## 金句摘录
> 当我们考察社会在一年间提供的商品产品，那么，就会清楚地看到：社会资本的再生产过程是怎样进行的，这个再生产过程和单个资本的再生产过程相比有哪些不同的特征，二者又有哪些共同的特征。（第254页）
> 当再生产（无论是简单的，还是规模扩大的）正常进行时，由资本主义生产者预付到流通中去的货币，必须流回到它的起点（无论这些货币是他们自己的，还是借来的）。这是一个规律。（第267页）
> 在这种生产的自发形式中，平衡本身就是一种偶然现象。（第281页）
> ……不变资本的生产，从来不是为了不变资本本身而进行的，而只是因为那些生产个人消费品的生产部门需要更多的不变资本。（第278页）
> 一切平衡都是偶然的，各个领域中使用资本的比例固然通过一个经常的过程达到平衡，但是这个过程的经常性本身，正是以它必须经常地、往往是强制地进行平衡的那种经常的比例失调为前提。（第282页）
> 增长最快的是制造生产资料的生产资料生产，其次是制造消费资料的生产资料生产，最慢的是消费资料生产。（列宁，第278页）

## 本章结构
- 第一节：个别资本和社会资本——社会资本运动的特征：包含个人消费和一般商品流通；研究出发点：社会总产品（总商品资本）；马克思再生产理论的两个基本原理：价值构成三部分（c+v+m）和实物构成两大部类；对魁奈《经济表》和"斯密教条"的批判
- 第二节：简单再生产条件下社会产品的实现——基本实现条件I(v+m)=IIc及两个引申条件；第二部类内部两个副类（必需品与奢侈品）的比例关系；货币流通在实现过程中的媒介作用；固定资本补偿的特殊性
- 第三节：扩大再生产条件下社会产品的实现——前提条件I(v+m)>IIc；基本实现条件I(v+Δv+m/x)=II(c+Δc)；技术进步条件下生产资料生产优先增长的原理
- 第四节：资本主义条件下社会产品实现过程的矛盾和困难——生产社会性与私人占有的矛盾、生产无限扩大趋势与有支付能力需求缩小的矛盾导致实现条件经常被破坏；批判民粹派和"合法马克思主义者"对实现论的曲解
