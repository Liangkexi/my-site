# 执行过程组

## 考情分析
- 考试分值：约8～12分（含案例分析），是项目管理三大核心过程组之一
- 常见题型：选择题 + 案例分析
- 执行过程组**耗费绝大多数项目预算、资源和时间**
- **高频考点**：获取资源、建设团队、管理团队、管理沟通

## 核心考点

### 一、执行过程组概述

执行过程组包含**10个过程**：

| 过程 | 所属知识领域 |
|------|------------|
| **指导与管理项目工作** | 项目整合管理 |
| **管理项目知识** | 项目整合管理 |
| **管理质量** | 项目质量管理 |
| **获取资源** | 项目资源管理 |
| **建设团队** | 项目资源管理 |
| **管理团队** | 项目资源管理 |
| **管理沟通** | 项目沟通管理 |
| **实施风险应对** | 项目风险管理 |
| **实施采购** | 项目采购管理 |
| **管理干系人参与** | 项目干系人管理 |

**执行过程组11类工作**：获取团队/实物资源 → 组建建设管理团队 → 开展采购 → 领导团队执行工作（收集工作绩效数据）→ 管理质量 → 执行变更请求 → 实施风险应对 → 管理沟通 → 管理干系人参与 → 管理项目知识 → 执行采购

### 二、指导与管理项目工作（12.1）

为实现项目目标而领导和执行项目管理计划中确定的工作。

**主要输入**：项目管理计划、项目文件（变更日志、经验教训登记册、里程碑清单等）、批准的变更请求

**主要输出**：可交付成果、工作绩效数据、问题日志、变更请求

### 三、管理项目知识（12.2）

使用现有知识并生成新知识，以实现项目目标并帮助组织学习。

**主要输入**：项目管理计划、项目文件、可交付成果

**主要输出**：经验教训登记册

### 四、管理质量（12.3）

> 注意：**管理质量**（执行）≠ **控制质量**（监控）

把组织的质量政策用于项目，将质量管理计划转化为可执行的质量活动。

**主要工具与技术**：
- 数据收集（核对单）
- 数据分析（备选方案分析、文件分析、过程分析、根本原因分析）
- 决策（多标准决策分析）
- 质量审计
- 面向X的设计（DFX）

**主要输出**：质量报告、测试与评估文件

### 五、获取资源（12.4）

获取项目所需的团队成员、设施、设备、材料和其他资源。

**主要输入**：资源管理计划、采购文件

**主要工具与技术**：多标准决策分析、谈判、预分派、虚拟团队

**主要输出**：实物资源分配单、项目团队派工单、资源日历

### 六、建设团队（12.5）

提高工作能力，促进团队互动，改善团队整体氛围。

**塔克曼阶梯模型**（高频考点）：

| 阶段 | 特征 |
|------|------|
| **形成期** | 团队成员相互认识，了解项目目标 |
| **震荡期** | 冲突频发，意见分歧 |
| **规范期** | 协同工作，建立信任 |
| **成熟期** | 高效运作，主动解决问题 |
| **解散期** | 项目结束，团队解散 |

> 任何团队都按此顺序发展，但可能停滞在某个阶段，也可能倒退。

**主要工具**：集中办公、虚拟团队、沟通技术、团建活动、认可与奖励、培训、个人和团队评估

### 七、管理团队（12.6）

跟踪团队成员工作表现，提供反馈，解决问题并管理变更。

**冲突管理**（5种策略，高频考点）：
| 策略 | 特征 | 适用场景 |
|------|------|---------|
| **合作/解决问题** | 双赢，最佳方式 | 有充分时间 |
| **强制/命令** | 赢-输，快速解决 | 紧急情况 |
| **妥协/调解** | 各退一步 | 双方势均力敌 |
| **缓和/包容** | 强调共识，淡化分歧 | 维持关系优先 |
| **撤退/回避** | 推迟处理 | 问题不紧急 |

### 八、管理沟通（12.7）

确保项目信息及时、恰当地收集、生成、发布、存储、检索、管理和最终处置。

**沟通技术**：推式（发送给特定接收方）、拉式（接收方自行获取）、交互式（多方信息交换）

### 九、实施风险应对（12.8）

执行商定的风险应对计划。

**主要输出**：变更请求、风险登记册更新

### 十、实施采购（12.9）

获取卖方应答、选择卖方并授予合同。

**采购文档**：招标文件（RFP/RFQ）、采购工作说明书、独立成本估算

**主要工具**：专家判断、广告、投标人会议、建议书评价

### 十一、管理干系人参与（12.10）

与干系人沟通协作以满足其需求和期望，处理问题并促进干系人参与。

**主要输出**：变更请求、项目管理计划更新

## 记忆要点
- **塔克曼阶梯模型5阶段**：形成→震荡→规范→成熟→解散（形震规范成散）
- **冲突管理5策略速记**：合强妥缓撤（优选顺序从高到低）
- 管理质量 ≠ 控制质量（管理质量在**执行组**，控制质量在**监控组**）
- 获取资源的3种方式：预分派、谈判、虚拟团队
- 三种沟通方式：推式、拉式、交互式

## 常见题型
1. **选择题**：塔克曼阶梯模型中，团队成员开始协同工作、建立信任的阶段是（ ）→ 答案：规范期
2. **选择题**：冲突管理策略中，能产生双赢的最佳方式是（ ）→ 答案：合作/解决问题
3. **案例分析**：项目经理发现团队成员冲突频繁影响进度，应如何管理？→ 先用合作策略根本解决，紧急情况下可用强制策略
