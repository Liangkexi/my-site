# 信息化发展

## 考情分析
- 本章是全书基础章节，分值占比约3～5分
- 常见题型：选择题为主
- **高频考点**：信息的特征与质量属性、信息传输模型、系统特性、信息系统生命周期、数字中国、数字化转型

## 核心考点

### 一、信息基础（1.1.1）

**信息的定义**：1948年香农定义——"信息是用来消除随机不定性的东西"。信息量的单位为比特（bit）。信息与熵相反，是系统有序程度的度量，表现为负熵。

**信息的11个特征**：客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性。

**信息的7个质量属性**：
| 属性 | 含义 |
|------|------|
| **精确性** | 对事物状态描述的精准程度 |
| **完整性** | 描述全面程度，含所有重要事实 |
| **可靠性** | 来源、采集、传输过程可信任 |
| **及时性** | 获取时刻与事件发生时刻的间隔 |
| **经济性** | 获取传输成本可接受 |
| **可验证性** | 质量属性可被证实或证伪 |
| **安全性** | 被非授权访问的可能性 |

> 记忆技巧：精完可及经可安（精完可及经可安）

**信息传输模型**：信源 → 编码器 → 信道 → 译码器 → 信宿，全程受噪声影响。信息系统性能指标为**有效性**（传得多）和**可靠性**（失真小）。

### 二、信息系统基础（1.1.2）

**系统的9个特性**：目的性、整体性、层次性、稳定性、突变性、自组织性、相似性、相关性、环境适应性。

**信息系统的3个独有特性**：
- **开放性**：系统可被外部环境识别和访问
- **脆弱性**：可能丧失结构、功能、秩序，被侵入后整体性被破坏
- **健壮性（鲁棒性）**：能抵御非预期状态，通过冗余、容错、身份识别、可靠性技术保障

**信息系统生命周期**（5阶段）：
1. **系统规划**（可行性分析、项目开发计划）→ 系统设计任务书
2. **系统分析**（需求分析，逻辑设计）→ 系统说明书
3. **系统设计**（概要设计+详细设计，物理设计）→ 系统设计说明书
4. **系统实施**（编码、测试、设备安装）→ 测试分析报告
5. **系统运行和维护**

从项目管理角度简化为：**立项 → 开发 → 运维 → 消亡**（4阶段）。
项目生命周期：**启动 → 计划 → 执行 → 收尾**。

### 三、信息化基础（1.1.3）

**信息化内涵**：信息化是推动经济社会发展与转型的历史性过程。用作名词指信息技术应用促成转变的过程；用作形容词指因深入应用达成的新形态。

**国家信息化体系六要素**：信息资源、信息网络、信息技术应用、信息技术和产业、信息化人才、信息化政策法规和标准规范。

### 四、现代化基础设施（1.2）

**新型基础设施建设**（2018年中央经济工作会议首次提出）：
- **信息基础设施**：5G、物联网、工业互联网、数据中心等
- **融合基础设施**：传统基础设施智能化改造
- **创新基础设施**：支撑科技创新的基础设施

**工业互联网**：四大体系——网络、平台、数据、安全。

**城市物联网**：感知层、网络层、平台层、应用层。

### 五、产业现代化（1.3）

- **农业农村现代化**：数字乡村、智慧农业
- **工业现代化**：智能制造（关键能力要素：设计、生产、管理、服务）
- **服务现代化**：现代服务业与制造业融合发展

### 六、数字中国（1.4）

| 要素 | 核心内容 |
|------|---------|
| **数字经济** | 数字产业化 + 产业数字化，数据为新型生产要素 |
| **数字政府** | "一网通办"、数据共享、协同治理 |
| **数字社会** | 智慧城市、数字乡村、数字生活 |
| **数字生态** | 数据安全、隐私保护、数字规则 |

### 七、数字化转型与元宇宙（1.5）

**数字化转型**：以数据为驱动，通过新一代信息技术与业务深度融合，实现组织战略、业务模式、组织架构的革新。

**元宇宙**：人类社会的三元空间——物理空间、社会空间、信息空间。元宇宙是信息空间的新形态，具有虚实融合、沉浸式体验等特征。
