# 监理基础知识

## 考情分析
- 本章介绍信息系统工程监理的基础知识，内容相对独立
- 选择题高频考点：监理对象（五大类）、**"三控两管一协调"**、监理技术参考模型四部分、监理文件（大纲/规划/实施细则）的区别、监理各阶段活动
- 简答题较少涉及，以基本概念为主
- 预计分值：选择题2~3分

## 核心考点

### 16.1 监理的意义和作用

**监理对象（五大类）：** 信息网络系统、信息资源系统、信息应用系统、信息安全、运行维护

**监理的地位和作用：**
1. 为项目业主单位提供信息系统工程相关的**技术建议**
2. 代表项目业主单位对项目实施过程进行全程的**跟踪和监督管理**
3. 保证项目交付成果的**质量**
4. 协调项目干系人间的**关系**，促进信息共享

**监理重要性突出的6个原因：**
1. 信息系统工程关系到国家、企业、单位的重要业务
2. 信息系统工程往往需求不明确时就实施，实施过程中需要不断修改
3. 用户需求不断变化，存在不能按预定进度执行的问题和风险
4. 信息系统工程项目投资相对较大，管理不善会造成较大浪费
5. 信息系统工程的实施过程存在**隐蔽工程**，可视性差，容易产生工程隐患
6. 存在"重建设，轻管理"问题，业主单位缺乏足够技术能力监管

**监理技术参考模型（四部分）：**
1. **监理支撑要素**：法规及管理文件、合同、服务能力（人员、技术、资源、流程）
2. **监理运行周期**：规划设计→部署实施→运行维护
3. **监理对象**：信息应用系统、信息资源系统、信息网络系统、信息安全、运行维护
4. **监理内容**：质量、进度、投资控制；合同、文档资料管理；协调各方工作关系

**"三控、两管、一协调"（核心概念，必背！）：**
- **三控**：质量控制、进度控制、投资控制
- **两管**：合同管理、信息（文档资料）管理
- **一协调**：协调有关单位及人员间的工作关系

### 16.2 监理相关概念

**主要概念：**
- **信息系统工程监理**：具有监理能力及资格的单位受业主单位委托，依据国家法律法规、技术标准和监理合同，对信息系统工程项目实施的监督管理
- **监理单位**：具有独立企业法人资格，具备规定数量的监理工程师和注册资金等的企业
- **业主单位（建设单位）**：具有信息系统工程发包主体资格和支付能力的单位
- **承建单位**：具有独立企业法人资格，具有承接信息系统工程建设能力的单位
- **监理机构**：监理单位对信息系统工程项目实施监理时，负责履行监理合同的组织机构

**监理人员：**
- **监理工程师**：正式聘任的，取得国家相关主管部门颁发的资格证书的专业技术人员
- **总监理工程师**：由监理单位法定代表人书面授权，全面负责监理合同履行，主持监理机构工作
- **总监理工程师代表**：由总监理工程师书面授权，代表行使其部分职责和权力
- **监理员**：经过监理业务培训，具有同类工程相关专业知识，从事具体监理工作

**监理文件（5种，必考！）：**
1. **监理大纲**：投标阶段由监理单位编制，经法定代表人（或授权代表）书面批准，用于争取监理合同的**纲领性文件**。编制依据：业主对监理工作的要求（监理招标文件）、服务质量管理体系、监理及相关服务规范、法律法规和技术标准规范
2. **监理规划**：签订监理合同后，**总监理工程师主持编制**，经监理单位技术负责人书面批准，指导监理机构全面开展监理工作的**指导性文件**。需报送业主单位确认后生效
3. **监理实施细则**：根据监理规划，由**监理工程师编制**，经总监理工程师书面批准，针对某一方面或某一专业的**操作性文件**
4. **监理意见**：监理机构以书面形式向业主单位或承建单位提出的见解和主张
5. **监理报告**：监理机构对阶段性进展、专项问题或临时事件形成的书面陈述

**监理过程（3种形式）：**
- **全过程监理**：覆盖招标、设计、实施、验收的全过程（含运行维护部分）
- **里程碑监理**：对工程里程碑产生的结果进行确认
- **阶段监理**：开展某个或某些特定阶段的监理工作

**监理形式（4种）：**
- **监理例会**：由监理机构主持，定期召开，针对质量、进度、投资控制和合同、文档资料管理以及协调各方关系
- **签认**：任何一方签署并认可其他方所提供文件的活动
- **现场（驻场服务）**：监理人员在项目执行期间一直在项目现场开展监理服务
- **旁站**：在关键部位或关键工序施工过程中，由监理人员在现场进行的监督或见证活动

### 16.3 监理依据

**监理国家标准（GB/T 19668系列）：**
- GB/T 19668.1《总则》
- GB/T 19668.2《基础设施工程监理规范》
- GB/T 19668.3《运行维护监理规范》
- GB/T 19668.4《信息安全监理规范》
- GB/T 19668.5《软件工程监理规范》
- GB/T 19668.6《应用系统：数据中心工程监理规范》
- GB/T 19668.7《监理工作量度量要求》

**监理行业及团体标准：** T/CEA PJ系列（监理单位服务能力评估、从业人员能力要求、从业人员能力评价指南、服务成本度量指南、服务质量评价规范）

### 16.4 监理内容（按阶段）

1. **规划阶段**：
   - 协助业主单位构建信息系统架构
   - 提供项目规划设计相关服务
   - 对项目需求、项目计划和初步设计方案进行审查
   - 协助业主单位策划招标方法

2. **招标阶段**：
   - 参与招标前准备工作，协助编制项目工作计划
   - 参与招标文件的编制并对其内容提出监理意见
   - 协助业主单位进行招标工作（如委托招标则审核招标代理机构资质）
   - 向业主单位提供招投标咨询服务
   - 参与承建合同的签订过程，对承建合同内容提出监理意见

3. **设计阶段**：
   - 审查设计方案、测试验收方案、计划方案（不只审文档规范性，还应审内容的完整性、正确性和合理性）
   - 管理变更方案和文档资料（尤其版本控制和变更控制）

4. **实施阶段**：
   - 通过现场监督、核查、记录和协调，及时发现并督促承建单位纠正问题
   - 主要活动：质量控制、进度控制、投资控制、合同管理、文档资料管理和协调

5. **验收阶段**：
   - 审核项目测试验收方案的符合性及可行性
   - 协调承建单位配合第三方测试机构进行系统测评
   - 促使项目最终功能和性能符合承建合同、法律法规和标准要求
   - 促使技术、管理文档的内容和种类符合相关标准
   - 坚持以**测试为基础、以事实为依据**的验收工作原则

### 16.5 监理要素

#### 16.5.1 监理合同
- 内容主要包括：监理及相关服务内容、服务周期、双方权利和义务、费用计取和支付、违约责任及争议解决办法
- 宜采用全过程监理，也可采用里程碑监理或阶段监理

#### 16.5.2 监理服务能力（人员、技术、资源、流程）

**1. 人员：** 总监理工程师、总监理工程师代表、监理工程师、监理员。应有人力资源管理制度（招聘与配置、培训与开发、绩效管理、薪酬管理）

**2. 技术：**
- **监理工作体系**：组织体系、管理体系、文档体系
- **质量管理体系**：覆盖所有监理及相关服务业务
- **监理主要技术与管理手段**：检查、旁站、抽查、测试、软件特性分析
- 监理知识库：具备知识的添加、更新和查询功能；知识生命周期管理（体系构建→采集→检查→应用→评价→维护）

**3. 资源：**
- 监理机构：完成监理合同规定内容后方可撤销
- 监理知识库和监理案例库
- 检测分析工具及仪器设备
- 企业管理信息系统

**4. 流程：**
- 项目管理体系：有负责项目管理的部门、制度和流程、评价方法、知识库和工具
- 客户服务体系：专门机构和人员、满意度调查和投诉处理机制
- 监理及相关服务的制度和流程

## 记忆要点
1. **监理对象五类**：网络、资源、应用、安全、运维
2. **三控两管一协调**：质量、进度、投资 + 合同、信息 + 协调
3. **监理文件三层次**：大纲（投标阶段/纲领性）→规划（合同后/指导性）→细则（专业/操作性）
4. **技术参考模型4部分**：支撑要素、运行周期、监理对象、监理内容
5. **服务能力4要素**：人员、技术、资源、流程
6. **监理过程3种**：全过程、里程碑、阶段
7. **监理形式4种**：例会、签认、现场（驻场）、旁站
8. **验收原则**：以测试为基础、以事实为依据

## 常见题型
1. **选择题**：不属于信息系统工程监理对象的是？
   - 答：C. 信息技术服务组织
2. **选择题**：监理服务能力重点关注？
   - 答：B. 人员、技术、资源、流程
3. **选择题**：不属于规划阶段监理服务基础活动的是？
   - 答：C. 在业主单位授权下，参与业主单位招标前的准备工作，协助业主单位编制项目的工作计划（这是招标阶段的活动）
4. **选择题**："三控、两管、一协调"中"三控"不包括？
   - 答：信息安全控制（三控是质量、进度、投资）
