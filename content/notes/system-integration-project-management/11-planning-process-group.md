# 规划过程组

## 考情分析
- **全书最重要章节**，考试分值约15～25分，占项目管理部分的50%+
- 常见题型：选择题 + 案例分析（几乎每道案例分析都涉及规划过程）
- **高频考点**：项目管理计划、WBS、进度网络图/关键路径、挣值管理基础、风险分析

### 二、制定项目管理计划（11.1）

**主要输入**：项目章程 + 其他规划过程的输出

**项目管理计划组件**：10个子计划 + 3大基准（**范围基准、进度基准、成本基准**）+ 其他组件

> 基准一旦确定，只能通过提出变更请求、实施整体变更控制过程更新。

### 三、范围管理（11.2～11.5）

#### 规划范围管理（11.2）
输出：**范围管理计划**、需求管理计划

#### 收集需求（11.3）
工具：头脑风暴、访谈、焦点小组、问卷调查、标杆对照、**亲和图**、**思维导图**、名义小组技术

输出：**需求文件**、需求跟踪矩阵

#### 定义范围（11.4）
对需求进行筛选，详细描述项目和产品。

输出：**项目范围说明书**（包含：产品范围描述、可交付成果、验收标准、除外责任）

#### 创建WBS（11.5）—— **高频考点**

**WBS**（工作分解结构）：以可交付成果为导向的工作层级分解。

**分解原则**：
- 工作包是最底层，通常控制在**80小时**以内
- **100%规则**：WBS包含项目全部工作范围
- 不能分解的"工作包"即最底层

**WBS词典**：对WBS中每个组件的详细说明

**范围基准** = 范围说明书 + WBS + WBS词典

### 四、进度管理（11.6～11.10）

#### 排列活动顺序（11.8）

**PDM**（紧前关系绘图法）：4种依赖关系：
| 类型 | 缩写 | 含义 |
|------|------|------|
| 完成-开始 | FS | 前活动完成后，后活动才能开始 |
| 完成-完成 | FF | 前活动完成后，后活动才能完成 |
| 开始-开始 | SS | 前活动开始后，后活动才能开始 |
| 开始-完成 | SF | 前活动开始后，后活动才能完成 |

**依赖类型**：强制性依赖（硬逻辑）、选择性依赖（软逻辑）、外部依赖、内部依赖

#### 估算活动持续时间（11.9）
工具：专家判断、**类比估算**、**参数估算**、**三点估算**、自下而上估算

**三点估算公式**（高频考点）：
- 期望时间 **tE = (tO + 4tM + tP) / 6**
- 标准差 σ = (tP - tO) / 6

#### 制订进度计划（11.10）—— **高频考点**

**关键路径法（CPM）**：项目从开始到结束的**最长路径**，决定项目最短工期。关键路径上活动的**总浮动时间为0**。

**总浮动时间**：活动可以延误而不影响总工期的时间。
**自由浮动时间**：活动可以延误而不影响紧后活动最早开始的时间。

**进度压缩技术**：
| 技术 | 方法 | 副作用 |
|------|------|--------|
| **赶工** | 增加资源 | 成本增加 |
| **快速跟进** | 并行开展活动 | 风险增加，可能返工 |

### 五、成本管理（11.11～11.13）

#### 估算成本（11.12）
输入：成本管理计划、范围基准
输出：活动成本估算、估算依据

#### 制定预算（11.13）

**成本基准**：经批准的按时间段分配的项目预算，是**S曲线**的基础。

**项目预算** = 成本基准 + 管理储备
**成本基准** = 项目估算 + 应急储备

### 六、规划质量管理（11.14）

质量管理计划包括质量标准和目标。

**质量成本（COQ）**：
- **一致性成本**（预防+评估）：培训、测试
- **非一致性成本**（内部失败+外部失败）：返工、赔偿

### 七、规划资源管理（11.15）

输出：**资源管理计划**、团队章程

团队章程内容包括：团队价值观、沟通指南、决策标准、冲突处理原则。

### 八、规划风险管理（11.18～11.22）

#### 风险基本概念
- **单个项目风险**与**整体项目风险**
- 风险三要素：风险事件、概率、影响
- 风险分类：按来源（技术、管理、商业、外部）、按影响（威胁/机会）

#### 识别风险（11.19）
输出：**风险登记册**（风险清单 + 潜在风险责任人 + 潜在风险应对）

#### 实施定性风险分析（11.20）

通过评估概率和影响对风险优先级排序。

**概率和影响矩阵**：将风险分为高、中、低三个等级。

#### 实施定量风险分析（11.21）

工具：**蒙特卡洛模拟**（模拟成本/进度分布）、**决策树分析**（期望货币价值EMV）、敏感性分析（**龙卷风图**）

#### 规划风险应对（11.22）

| 策略（威胁） | 含义 |
|-------------|------|
| **上报** | 超出项目经理权限 |
| **规避** | 消除威胁 |
| **转移** | 转给第三方（如保险） |
| **减轻** | 降低概率或影响 |
| **接受** | 主动接受（储备）或被动接受 |

| 策略（机会） | 含义 |
|-------------|------|
| **开拓** | 确保机会实现 |
| **分享** | 与第三方合作 |
| **提高** | 增加概率或影响 |
| **接受** | 不主动追求 |

### 九、规划采购管理（11.23）

**合同类型**（高频考点）：
| 合同类型 | 特征 | 买方风险 |
|---------|------|---------|
| **固定总价（FFP）** | 总价固定 | 低 |
| **成本补偿合同** | 实报实销 | 高 |
| **工料合同（T&M）** | 按工时+材料 | 中等 |

### 十、规划干系人参与（11.24）

输出：**干系人参与计划**

干系人参与度分类：
- **不知晓**：不了解项目
- **抵制**：反对项目
- **中立**：既不支持也不反对
- **支持**：支持项目
- **领导**：积极参与

## 记忆要点
- 24个过程口诀："制定范围收定W，进度5个成本3，质量资源沟通1，风险5个采购干"
- **范围基准** = 范围说明书 + WBS + WBS词典（3合1）
- **三点估算**：tE = (O+4M+P)/6，σ = (P-O)/6
- **关键路径** = 最长的路 = 最少浮动时间（总时差=0）
- **进度压缩**：赶工（加钱）vs 快速跟进（并行，加风险）
- **威胁五策**：上报/规避/转移/减轻/接受（上规转减接）
- **机会四策**：开拓/分享/提高/接受
- **合同三类型**：固定总价/成本补偿/工料（风险从小到大）

## 常见题型
1. **选择题**：WBS的最底层是（ ）→ 答案：工作包
2. **选择题**：关键路径是指（ ）→ 答案：项目中时间最长的活动顺序
3. **计算题**：已知tO=3, tM=6, tP=15，求tE和σ → tE=7, σ=2
4. **案例分析**：给出活动依赖关系，画出网络图，求关键路径和总工期
