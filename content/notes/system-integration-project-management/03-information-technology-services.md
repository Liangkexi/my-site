# 信息技术服务

## 考情分析
- 本章为IT服务专业章节，分值占比约3～5分
- 常见题型：选择题为主
- **高频考点**：IT服务四要素、服务生命周期四阶段、ITSS体系、服务产业化进程、服务质量模型

## 核心考点

### 一、IT服务组成要素（3.2）

IT服务由四个核心要素组成：**人员（People）、过程（Process）、技术（Technology）、资源（Resource）**，简称PPTR。

| 要素 | 核心作用 | 关键点 |
|------|------|------|
| **人员** | 正确选人 | 知识、技能、经验 |
| **过程** | 正确做事 | 流程化、规范化 |
| **技术** | 高效做事 | 技术研发与应用 |
| **资源** | 保障做事 | 知识库、工具库、备件库、服务台 |

四要素关系：人员、过程、技术三要素的成果固化转化为资源，资源又反过来支撑另外三个要素。

### 二、服务生命周期（3.3）

IT服务生命周期（SDOR模型）分为四个阶段：

| 阶段 | 核心活动 |
|------|------|
| **战略规划** | 从业务战略出发，规划服务目录、组织架构、指标体系、服务保障体系 |
| **设计实现** | 依据战略规划，进行服务设计与部署，建立管理体系、部署工具和解决方案 |
| **运营提升** | 全面管理基础设施、服务过程、人员和业务连续性，持续改进 |
| **退役终止** | 残余价值分析，部分或全部替换，停止无价值服务 |

**战略规划阶段关键成功因素**：
- 全面考虑业务战略、团队建设、管理过程、技术研发、资源储备的战略规划
- 确保战略规划得到决策层、管理层的承诺和支持
- 得到相关干系人的理解和支持

**设计实现阶段**：服务设计需识别和控制四大风险——**技术风险**、**管理风险**、**成本风险**、**不可预测风险**。服务部署分为**计划、启动、执行、交付**四个阶段。

**运营提升**：占服务整体生命周期约80%。关键成功因素包括：服务交付满足业务需求、促进需方业务价值提升、服务质量一致性和标准化能力。

### 三、服务标准化（3.4）

**IT服务产业化三阶段**：

| 阶段 | 定位 | 特征 |
|------|------|------|
| **产品服务化** | 前提 | 服务依附于产品；缺乏明确考核 |
| **服务标准化** | 保障 | 标准过程、规范制度；可追溯、可审计 |
| **服务产品化** | 趋势 | 清晰服务目录；独立价值、明确功能；全生命周期管理 |

### 四、ITSS标准体系（3.4.2）

ITSS 5.0体系框架由六大类标准组成：

| 类别 | 说明 |
|------|------|
| **通用标准** | 业务分类、服务质量评价、人员能力要求等共性标准 |
| **保障标准** | 服务管控标准（治理、管理、监理）和服务外包标准 |
| **基础服务标准** | 咨询设计、开发服务、集成实施、运行维护、云服务、数据中心 |
| **技术创新服务标准** | 智能化服务、数据服务、数字内容处理、区块链服务 |
| **数字化转型服务标准** | 成熟度模型、就绪度评估、效果评价等 |
| **业务融合标准** | IT服务与政务、广电、教育、应急、财会等行业融合 |

ITSS建设目标：支撑国家战略、引领产业高质量发展、促进新技术创新应用、指导IT服务业务升级、确保标准化工作有序开展。

### 五、服务质量评价（3.5）

**IT服务质量模型**（GB/T3850）定义五大质量特性：

| 特性 | 含义 | 子特性 |
|------|------|------|
| **安全性** | 保障需方信息安全 | 可用性、完整性、保密性 |
| **可靠性** | 履行服务协议程度 | 完备性、连续性、稳定性、有效性、可追溯性 |
| **响应性** | 及时受理服务请求 | 及时性、互动性 |
| **有形性** | 通过实体证据展现服务 | 可视性、专业性、合规性 |
| **友好性** | 为需方着想和关注 | 主动性、灵活性、礼貌性 |

**服务质量互动模型**：需方的**期望质量**与**感知质量**对比——期望 > 感知（不满意）；期望 ≤ 感知（满意）。供方的服务要素质量支撑服务生产质量。

### 六、服务发展现状与趋势（3.6）

- 传统服务转型升级：咨询设计向业务数字化转型、开发模式向微服务转变、集成实施向全栈式转变、运维向智能运维（AIOps）转变
- 新模式新业态：数据服务、区块链服务、数字内容处理服务、数字化转型服务
- 复合型人才需求旺盛
- 发展与安全长期共存

### 七、服务集成（3.7）

服务集成是以信息系统平台为基础的多元服务融合集成。与单项服务相比，更关注：业务战略一致性管控、服务敏捷与创新、服务能力与服务生态一致性。

服务集成四大原则：
- 以稳态发展规律，推演创新实施路径
- 以成熟实践方法，保驾创新融合内容
- 以合规评估评测，确立创新核心价值
- 以多元专家参与，支撑创新建设优化

## 记忆要点
- **IT服务四要素**：人员、过程、技术、资源（PPTR）
- **生命周期四阶段**：战略规划→设计实现→运营提升→退役终止
- **产业化三阶段**：产品服务化→服务标准化→服务产品化
- **服务质量五特性**：安全、可靠、响应、有形、友好
- **ITSS 5.0六大标准**：通用、保障、基础、技术创新、数字化转型、业务融合

## 常见题型
1. **选择题**：IT服务组成要素包括（人员、过程、技术、资源）
2. **选择题**：IT服务生命周期不包括哪个阶段（选项制造干扰，正确答案为战略规划、设计实现、运营提升、退役终止）
3. **选择题**：不属于IT服务产业化进程的是（"服务数字化"——正确路径是产品服务化→服务标准化→服务产品化）
4. **选择题**：IT服务质量模型中"响应性"的子特性包括（及时性、互动性）
