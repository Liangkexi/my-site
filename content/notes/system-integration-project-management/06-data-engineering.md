# 数据工程

## 考情分析
- 本章为数据工程基础章节，分值占比约3～5分
- 常见题型：选择题为主
- **高频考点**：数据采集方法、预处理方法、数据模型三类、备份策略对比、数据挖掘任务、元数据类型、数据标准化阶段

## 核心考点

### 一、数据采集和预处理（6.1）

**数据类型**：
- **结构化数据**：关系型数据库表管理
- **半结构化数据**：有基本结构模式，如日志文件、XML、JSON、E-mail
- **非结构化数据**：无固定模式，如办公文档、文本、图片、音频/视频

**数据采集方法**：

| 方法 | 说明 |
|------|------|
| **传感器采集** | 通过传感器感知信息，将其变换为电信号输出 |
| **系统日志采集** | 读取收集日志文件，常用工具有Logstash、Filebeat、Flume |
| **网络采集** | 通过API接口或网络爬虫获取数据 |
| **其他采集** | 与数据服务商合作等方式 |

**网络爬虫分类**：通用网络爬虫、聚焦网络爬虫、增量式网络爬虫、深层网络爬虫。

**数据预处理流程**：数据分析（定义清理规则和算法）→ 数据检测（检测正确性和重复）→ 数据修正（手工或自动修正错误）。

**常见数据问题及预处理方法**：

| 问题类型 | 处理方法 |
|------|------|
| **数据缺失** | 删除缺失值、均值填补法、热卡填补法、回归填补法 |
| **数据异常（噪声）** | 分箱法（考察近邻平滑数据）、回归法（用函数拟合） |
| **数据不一致** | 人工修改、工具修改、数据变换 |
| **数据重复** | 最后进行去重，可用Excel、VBA、Python |
| **格式不符** | 统一清洗为统一类型和格式 |

### 二、数据存储及管理（6.2）

**存储介质**：磁带（低成本大容量但速度慢）、光盘（只读、不受电磁影响、适合归档）、磁盘（RAID）、内存（断电丢失）、闪存（固态）、云存储（异地可扩展）。

**三种存储形式**：

| 存储形式 | 特点 |
|------|------|
| **文件存储** | 分层的存储方法，文件→文件夹→目录 |
| **块存储** | 数据存储成块，每块有唯一标识符，快速高效 |
| **对象存储** | 处理非结构化数据（邮件、视频、照片等） |

**备份策略对比**：

| 策略 | 描述 | 效率 | 恢复 |
|------|------|------|------|
| **完全备份** | 每次全备份 | 资源消耗大 | 最简单 |
| **差分备份** | 备份相对上次完全备份的变化 | 较省空间 | 需完全+最后差分 |
| **增量备份** | 备份相对上次任何备份的变化 | 最省空间 | 最复杂，某增量损坏影响后续 |

**数据容灾两个关键指标**：
- **RPO**（恢复点目标）：允许丢失的数据量
- **RTO**（恢复时间目标）：系统恢复所需时间

**容灾关键技术**：远程镜像技术（主镜像+从镜像远程同步）、快照技术（某时间点的完整复制，可在线恢复）。

### 三、数据治理和建模（6.3）

#### （1）元数据

元数据是关于数据的数据，是对信息资源的结构化描述。

**元数据体系五层级**（自上而下）：
内容元数据 → 专门元数据 → 资源集合元数据 → 管理元数据 → 服务元数据 → 元元数据（对元数据的描述）。

**元数据五大作用**：描述、资源发现、组织管理数据资源、互操作性、归档和保存数据资源。

#### （2）数据标准化

**四个阶段**：确定数据需求 → 制定数据标准 → 批准数据标准 → 实施数据标准。

主要内容：元数据标准化、数据元标准化、数据模式标准化、数据分类与编码标准化。

#### （3）数据质量

**数据质量评价过程**（五步）：
1. 确定适用的数据质量定量元素及数据质量范围
2. 确定数据质量度量方法
3. 选择并使用数据质量评价方法
4. 确定数据质量结果
5. 报告数据质量结果

**评价方法**：直接评价法（与参照信息对比）、间接评价法（利用相关信息推断）。

**质量控制**：前期控制（录入前+录入时）+ 后期控制（录入后）。

#### （4）数据模型三类

| 模型 | 定位 | 基本元素 | 特点 |
|------|------|------|------|
| **概念模型** | 用户观点，信息抽象 | 实体、属性、域、键、关联 | 不依赖具体计算机系统 |
| **逻辑模型** | 确定数据结构 | 关系、属性、视图 | 关系模型是最重要的逻辑模型 |
| **物理模型** | 真正数据存放 | 表、字段、视图、索引、存储过程 | 考虑具体DBMS实现 |

**关系的完整性约束**：实体完整性、参照完整性、用户定义的完整性。

**数据建模流程**：数据需求分析 → 概念模型设计 → 逻辑模型设计 → 物理模型设计。

### 四、数据仓库和数据资产（6.4）

**数据仓库四组件**：数据源 → 数据的存储与管理 → OLAP服务器 → 前端工具。

**OLAP三种实现**：
- **ROLAP**：基于关系数据库
- **MOLAP**：基于多维数据库
- **HOLAP**：混合模式（基本数据在关系库，聚合数据在多维库）

**数据资产管理（DAM）**：对数据资产进行规划、控制和提供的一组活动职能。

**数据价值的两个环节**：
- **数据资源化**：原始数据变为数据资源，以数据治理为重点
- **数据资产化**：数据资源变为数据资产，释放潜在价值

**数据资产流通三模式**：数据共享（组织内部）、数据开放（面向公众）、数据交易（合同约定）。

**数据资源目录三层**：
- **资源目录**：原始数据资源索引
- **资产目录**：标准化处理后的数据资产登记
- **服务目录**：对外提供的可视化共享数据目录（指标报表+共享接口）

### 五、数据分析及应用（6.5）

**数据集成常用方法**：
- **模式集成**（虚拟视图）：构建全局模式，用户透明访问
- **复制集成**：将数据复制到其他数据源，维护一致性
- **混合集成**：两者结合，简单请求用复制，复杂请求用模式集成

**数据访问接口**：ODBC（开放数据库连接）、JDBC（Java数据库连接）、OLE DB、ADO。

**Web Services三要素**：WSDL（服务描述）、SOAP（消息传递协议）、UDDI（注册服务规范）。

**数据挖掘与传统数据分析的区别**：

| 维度 | 传统数据分析 | 数据挖掘 |
|------|------|------|
| 数据量 | 较小 | 大，数据量越大效果越好 |
| 分析方法 | 统计学方法 | 数理统计+人工智能+可视化 |
| 分析侧重 | 回顾型、验证型 | 预测型、发现型 |
| 成熟度 | 较成熟 | 部分方法仍在发展 |

**数据挖掘五大任务**：数据总结、关联分析、分类和预测、聚类分析、孤立点分析。

**数据挖掘流程五阶段**：确定分析对象 → 数据准备（选择+预处理）→ 数据挖掘（模型构建+挖掘处理）→ 结果评估 → 结果应用。

### 六、数据脱敏和分类分级（6.6）

**数据脱敏**：对敏感信息进行模糊化、加扰、加密或转换后形成新数据，在非生产环境安全使用。

**脱敏方式**：
- **可恢复**：脱敏后可恢复（如加解密算法）
- **不可恢复**：脱敏后不可恢复（替换算法、生成算法）

**数据脱敏六大原则**：算法不可逆、保持数据特征、保留引用完整性、规避融合风险、过程自动化、结果可重复。

**数据敏感程度五级**：L1（公开）、L2（保密）、L3（机密）、L4（绝密）、L5（私密）。

**数据分级基本框架**（从国家数据安全角度）：

| 级别 | 国家安全 | 公共利益 | 组织/个人合法权益 |
|------|------|------|------|
| **核心数据** | 严重危害 | 严重危害 | — |
| **重要数据** | 一般/轻微危害 | 一般/轻微危害 | — |
| **一般数据** | 无危害 | 无危害 | 各种程度 |

## 记忆要点
- **三大数据类型**：结构化、半结构化、非结构化
- **三种备份策略**：完全（完整但费）、差分（折中）、增量（省但复杂）
- **容灾指标**：RPO（丢多少）、RTO（多长时间恢复）
- **三类数据模型**：概念（信息抽象）→ 逻辑（数据结构）→ 物理（存储实现）
- **OLAP三实现**：R→关系（ROLAP）、M→多维（MOLAP）、H→混合（HOLAP）
- **数据挖掘五任务**：总结、关联、分类预测、聚类、孤立点
- **数据敏感五级**：公开→保密→机密→绝密→私密
- **数据分级三级别**：一般→重要→核心

## 常见题型
1. **选择题**：不属于数据预处理促成因素的是（"数据安全"——应选缺失、不一致、重复、格式不符等）
2. **选择题**：衡量容灾系统的主要指标（RTO/RPO）
3. **选择题**：不属于数据质量评价过程的是（"确定第三方组织"）
4. **选择题**：数据集成的准确定义（将驻留在不同数据源中的数据进行整合）
5. **选择题**：敏感数据常见程度划分（L1公开、L2保密、L3机密、L4绝密、L5私密）
