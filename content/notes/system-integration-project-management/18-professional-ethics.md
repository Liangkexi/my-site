## 核心考点

### 18.1 基本概念

**道德：**
- 道德是由一定的社会经济关系所决定的特殊意识形态
- 道德具有**非强制性**，但与法律一样，都是调控社会关系和人们行为的重要机制
- 通俗讲：道德就是**自己管自己的一组规矩**
- 道德的主要功能是规范人们的思想和行为
- 道德是依靠**舆论、信念和习俗**等非强制性手段起作用的
- 道德以**善恶观念**为标准来评价人们的思想和行为

**职业道德：**
- 人们在从事职业活动时应该遵循的符合自身职业特点的行为规范
- 主要内容：**爱岗敬业、诚实守信、办事公道、服务群众、奉献社会**
- 职业道德涵盖：从业人员与服务对象、职业与人员、职业与职业之间的关系

**职业道德七个特征：**
1. **职业性**：必须通过从业者在职业活动中体现
2. **普遍性**：由职业性质决定，从业者群众多、范围广大
3. **自律性**：具有自我约束、控制的特征（与法律、纪律的区别所在）
4. **他律性**：具有影响舆论的特征
5. **鲜明的行业性和多样性**：各行各业都有适合自身特点的规范
6. **继承性和相对稳定性**：如诚信、互助与协作、勤俭节约等跨越国界和历史时代传承
7. **很强的实践性**：必须通过职业实践活动表现并接受评价

### 18.2 项目管理工程师职业道德规范（6条）

项目管理工程师应遵守的职业行为准则：
1. **爱岗敬业、遵纪守法、诚实守信、办事公道、与时俱进**
2. **梳理流程、建立体系、量化管理、优化改进、不断积累**
3. **对项目负管理责任，计划指挥有方，全面全程监控，善于解决问题，沟通及时到位**
4. **为客户创造价值，为雇主创造利润，为组员创造机会，合作多赢**
5. **积极进行团队建设，公平、公正、无私地对待每位项目团队成员**
6. **平等与客户相处；与客户协同工作时，注重礼仪；公务消费应合理并遵守有关标准**

### 18.3 项目管理工程师岗位职责

**项目管理工程师的职责：**
1. 不断提高个人的项目管理能力：
   - 在工作中表现出诚实正直的态度
   - 主动采用项目管理理念和方法
   - 提升个人的项目管理能力
   - **平衡项目干系人的利益**
   - 以合作和职业化方式与团队和项目干系人打交道
2. 贯彻执行国家和项目所在地政府的有关法律、法规和政策，执行所在单位的各项管理制度和有关技术规范标准
3. 对信息系统项目的全生命期进行有效控制，确保项目质量和工期，努力提高经济效益
4. 严格执行财务制度，加强财务管理，严格控制项目成本
5. 执行所在单位规定的应由项目管理工程师负责履行的各项条款

**项目管理工程师的权利：**
1. **组织项目团队**
2. **组织制订信息系统项目计划**，协调管理信息系统项目相关的人力、设备等资源
3. **协调信息系统项目内外部关系**，受委托签署有关合同、协议或其他文件

### 18.4 项目管理工程师对项目团队的责任

**高效项目团队的特征：**
- 建立了明确的项目目标
- 建立了清晰的团队规章制度
- 建立了学习型团队
- 培养团队成员养成严谨细致的工作作风
- 团队成员分工明确
- 建立和培养勇于承担责任、和谐协作的团队文化
- 善于利用项目团队中的**非正式组织**来提高团队凝聚力

**团队价值观（8项）：**
1. 信任
2. 遵守纪律
3. 良好的、方便的沟通机制与氛围
4. 尊重差异，求同存异
5. 经验交流与共享
6. **结果导向**
7. 勇于创新
8. （保持持续学习和进步）

### 18.5 提升个人道德修养水平

**修养定义：** 个人在政治、思想、道德品质、知识技能等方面，经过学习和自我锻炼所达到的一定水平

**职业道德行为修养：** 根据职业道德原则和规范的要求，在职业活动过程中进行自我教育、自我锻炼和自我改造，从而形成良好的职业道德品质

**传统文化中的道德修养：**
- 《易经》："天行健，君子以自强不息"、"地势坤，君子以厚德载物"
- 曾子："吾日三省吾身——为人谋而不忠乎？与朋友交而不信乎？传不习乎？"
- 《礼记》："身修而后家齐，家齐而后国治"

**项目管理工程师应做到：**
- 以身作则，公平、公正，乐观、自信，为团队成员起表率和榜样作用
- 要求别人做到的事情，自己首先要做到
- 己所不欲，勿施于人
- 积极主动地领导团队、承担责任，表现出"舍我其谁"的工作气魄
- 善于学习，不断提升自身的道德修养水平

## 记忆要点
1. **道德 vs 法律**：道德是非强制性的（靠舆论、信念、习俗），法律是国家强制力保证实施
2. **职业道德内容**口诀：爱岗敬业、诚实守信、办事公道、服务群众、奉献社会
3. **职业道德特征**口诀：职业普遍，自律他律，行业多样，继承稳定，实践性强
4. **职业道德规范6条**口诀：①爱岗敬业+遵纪守法；②建立体系+优化改进；③管理责任+全程监控；④客户雇主组员三赢；⑤公平公正团队建设；⑥平等客户+合理消费
5. **团队价值观8项**：信任、纪律、沟通、尊重差异、经验共享、结果导向、创新
6. **职责 vs 权利区分**：职责是"对全生命期控制、财务、合规"，权利是"组织团队、制订计划、协调关系"

## 常见题型
1. **选择题**：关于道德的描述不正确的是？
   - 答：D. 道德是由国家制定或认可，并具有普遍约束力的社会规范（这是法的定义，不是道德）
2. **选择题**：主要内容包括爱岗敬业、诚实守信、办事公道、服务群众和奉献社会，是指导和评价人们职业行为善恶的准则的是？
   - 答：B. 职业道德
3. **选择题**：项目管理工程师的职责不包括？
   - 答：C. 协调信息系统项目内外部关系，受委托签署有关合同、协议或其他文件（这是权利，不是职责）
4. **选择题**：项目管理工程师的价值观不包括？
   - 答：D. 封建迷信
