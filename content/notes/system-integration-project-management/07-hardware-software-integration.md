# 软硬件系统集成

## 考情分析
- 本章属于信息技术基础章节，分值占比约2～4分
- 常见题型：选择题为主
- **高频考点**：系统集成的概念与特点、网络集成（传输介质、交换技术）、操作系统分类与功能、中间件分类、软件构件标准（CORBA/COM/J2EE/.NET）、业务应用集成

## 核心考点

### 一、系统集成基础（7.1）

**系统集成的定义**：根据组织治理、管理、业务、服务等场景化需求，优选各种信息技术和产品，将各个分离的"信息孤岛"连接成为一个完整、可靠、经济和有效的整体，使之能彼此协调工作，发挥整体效益，达到整体优化的目的。

**系统集成的5个分类**：软件集成、硬件集成、网络集成、数据集成、业务应用集成。

**系统集成的核心思想**：以信息的集成为目标，功能的集成为结构，平台的集成为基础，人员的集成为保证。

**典型系统集成项目特点**：
- 集成交付队伍庞大，且连续性不强
- 设计人员高度专业化，需要多元化知识体系
- 涉及众多承包商，分散在多个地区
- 通常需要研制一定量的软硬件系统（尤其是信创产品适配）
- 通常采用大量新技术、前沿技术
- 集成果使用越来越友好，集成实施和运维变得更加复杂

**信创与系统集成发展**：信创（信息技术应用创新）作为数据安全、网络安全的基础，不仅是新基建的重要组成部分，也是各行各业数字化升级的"发动机"。信创集成需关注：技术与产品选型、快速迭代周期的适应、场景化创新驱动。

### 二、基础设施集成（7.2）

#### 2.1 弱电工程
弱电一般指交流20V、50Hz以下的用电。主要包括9类系统：

| 系统 | 拓扑结构 | 传输介质 |
|------|---------|---------|
| 电话通信系统 | 星形 | 三类（或以上）非屏蔽双绞线 |
| 计算机局域网系统 | 星形 | 五类或以上非屏蔽双绞线 |
| 音乐/广播系统 | 多路总线 | 铜芯绝缘导线 |
| 有线电视信号分配系统 | 树形 | 75Ω射频同轴电缆 |
| 视频监控系统 | 星形（视频）/总线（控制） | 视频同轴电缆或光纤 |
| 消防报警系统 | 多路总线 | 铜芯绝缘缆线 |
| 出入口控制系统/一卡通 | 因产品而异 | 因产品而异 |
| 停车收费管理系统 | 因产品而异 | 因产品而异 |
| 楼宇自控系统 | 因产品而异 | 因产品而异 |

#### 2.2 网络集成
**网络系统集成**：将网络基础设施、网络设备、网络系统软件、网络基础服务系统以及计算机硬件设备、软件系统等组织集成为一体，组建完整、可靠、经济、安全、高效的计算机网络系统的全过程。

**网络集成一般体系框架**包括5个子系统：

**（1）传输子系统**：传输介质分为无线（无线电波、微波、红外线）和有线（双绞线、同轴电缆、光纤）两大类。

**（2）交换子系统**：
- 局域网交换：共享式局域网（以太网、令牌环、FDDI）和交换式局域网
- 城域网交换：以IP和ATM电信技术为基础，光纤作为传输媒介
- 广域网交换：
  - **电路交换**：专用通信线路，时延小但利用率低
  - **报文交换**：存储转发，利用率高但时延大
  - **分组交换**：固定长度分组存储转发，利用率高、时延短、费用低
  - **混合交换**：同时使用电路交换和分组交换（如ATM）

**（3）安全子系统**：防火墙技术（分组过滤、代理服务器、应用网关）、数据加密技术（对称加密如DES、非对称加密如RSA）、访问控制（口令、密码、访问权限）

**（4）网管子系统**：保证网络良好运行，找出并解决瓶颈

**（5）服务子系统**：互联网服务、多媒体信息检索、信息点播、信息广播、远程计算等

#### 2.3 数据中心集成
数据中心集成包括机房建设、机柜集成、服务器集成、存储集成、网络设备集成、安全设备集成6个方面。

**服务器选型考虑因素**：①CPU的速度和数量；②内存容量和性能；③总线结构和类型；④磁盘容量和性能；⑤容错性能；⑥网络接口性能；⑦服务器软件等。

**存储集成考虑因素**：①磁盘阵列空间和类型；②配置硬盘数量；③RAID控制器结构；④支持RAID0/1/5或更多类型；⑤IOPS读写性能和数据传输能力；⑥高可靠性（冗余热插拔电源、风扇）。

**安全设备集成**：防火墙、网络入侵防御/检测系统、病毒过滤网关、漏洞扫描、主机监控与审计、网络安全审计、数据库审计、日志审计、Web应用防护、网页防篡改、安全管理平台、堡垒机、VPN系统等。

### 三、软件集成（7.3）

#### 3.1 基础软件集成

**1. 操作系统（OS）**
- **分类**：桌面操作系统、服务器操作系统、手机操作系统、嵌入式操作系统
- **功能角度分类**：批处理、实时、分时、网络、分布式操作系统
- **五大管理功能**：进程管理（进程调度）、存储管理（分配/共享/保护/扩张）、设备管理（分配/传输控制/独立性）、文件管理（存储空间/目录/操作/保护）、作业管理
- **国产操作系统**：中标麒麟、银河麒麟、深度Deepin、华为鸿蒙

**网络操作系统**：调度和管理网络资源，基本功能包括数据共享、设备共享、文件管理、名字服务、网络安全、网络管理、系统容错、网络互联、应用软件

**操作系统虚拟化**：架构分为容器实例层、容器管理层、内核资源层。与传统虚拟化最本质的不同：传统虚拟化需Guest OS，操作系统虚拟化通过共享Host OS内核取代Guest OS。

**2. 数据库**
数据库是按照数据结构来组织、存储和管理数据的仓库。数据库管理系统（DBMS）是数据库系统的核心组成部分。**分布式数据库**：地理上分散但逻辑上属于同一系统，注重节点自治性和数据分布透明性。

**3. 中间件**
中间件位于操作系统和应用软件之间，为上层应用提供运行与开发环境。

**中间件三大功能**：通信支持（最基本）、应用支持（提供统一平台和标准接口）、公共服务（提取共性功能支持复用）。

**中间件分类**（6类）：
| 类型 | 别称 | 核心特点 |
|------|------|---------|
| 事务式中间件 | 事务处理管理程序 | 应用最广泛；支持大量客户进程并发访问，高扩展性；用于金融、电信、电子政务 |
| 过程式中间件 | 远程过程调用中间件 | 客户机/服务器结构，支持同步/异步通信，异构支持好 |
| 面向消息的中间件 | 消息中间件 | 消息队列和消息传递两种模型，高效可靠异步通信 |
| 面向对象中间件 | 分布对象中间件 | 分布式计算+面向对象，提供通信服务 |
| 交易中间件 | — | 专门针对联机交易处理系统 |
| Web应用服务器 | — | Web服务器+应用服务器，J2EE架构为主流标准 |

**4. 办公软件**
- **流式软件**：所见即所得编辑文档，如WPS Office。保存流式文件，内容可编辑，不同环境显示效果可能不同（"跑版"现象）。
- **版式软件**：原封不动显示/打印，不可编辑修改正文。两种标准：国际PDF、国家标准OFD。版式文档不会"跑版"。

#### 3.2 应用软件集成
**应用软件集成**：根据软件需求，把现有软件构件重新组合，以较低成本、较高效率实现目的要求。被产业界公认的解决应用集成的最佳方式是**SOA**。

**应用软件集成的功能**：界面集成、功能集成、接口集成、数据集成。

**5大软件构件标准**：

| 标准 | 全称 | 核心特点 |
|------|------|---------|
| **CORBA** | 公共对象请求代理结构 | OMG制定；核心是ORB（对象请求代理）；包括对象服务（15种）、公共功能、域接口、应用接口 |
| **COM** | 组件对象模型 | 二进制代码对象（DLL或EXE）；面向对象、C/S模型、语言无关性、进程透明性、可重用性（包容和聚合两种机制） |
| **DCOM/COM+** | 分布式COM | DCOM通过RPC协议远程调用；COM+特性：真正的异步通信、事件服务、可伸缩性、继承MTS特性、可管理可配置、易于开发 |
| **.NET** | .NET开发框架 | CLR（通用语言运行环境）+ BCL（基础类库）+ ADO.NET（数据库访问）+ ASP.NET（网络编程） |
| **J2EE** | Java 2企业版 | 四层体系：客户端层、服务器端组件层（JSP/Servlet）、EJB层（商业逻辑）、信息系统层（JDBC访问DBMS） |

### 四、业务应用集成（7.4）

**业务应用集成（EAI）**：将独立的软件应用连接起来，实现协同工作。

**业务应用集成的3个技术要求**：
- 具有应用间的**互操作性**（信息的有意义交换，语用交换而非仅限于语法/语义交换）
- 具有分布式环境中应用的**可移植性**（系统重构/迁移不影响服务）
- 具有系统中应用分布的**透明性**（屏蔽分布的复杂性）

**业务应用集成的5大优势**：共享信息、提高敏捷性和效率、简化软件使用、降低IT投资和成本、优化业务流程。

**业务应用集成的工作原理**（3个组件）：应用编程接口（API）、事件驱动型操作、数据映射。

## 记忆要点
- **系统集成定义速记**：以信息集成为目标、功能集成为结构、平台集成为基础、人员集成为保证
- **网络传输介质**：无线（无线电波/微波/红外线）vs 有线（双绞线/同轴电缆/光纤）
- **广域网4种交换技术**：电路（专用线路、低利用率）、报文（存储转发）、分组（固定长度、高效）、混合（ATM）
- **中间件3功能**：通信支持（最基本）、应用支持、公共服务
- **中间件6分类速记**：事过面交货Web（事务式、过程式、面向消息、面向对象、交易、Web应用服务器）
- **5大构件标准速记**：CCD.N J（CORBA、COM、DCOM/COM+、.NET、J2EE）
- **流式vs版式**：流式可编辑但会"跑版"（WPS），版式不可编辑但精确一致（PDF/OFD）

## 常见题型
1. **选择题**：系统集成的说法辨析（如"系统集成不是只聚焦技术的融合活动，安全、产品、服务、人员也是关键因素"）
2. **选择题**：网络操作系统的主要任务——调度和管理网络资源
3. **选择题**：存储集成考虑因素（品牌不是常见考虑因素）
4. **选择题**：应用软件集成的代表性构件标准（COBIT不属于，CORBA/COM/J2EE属于）
5. **选择题**：操作系统功能识别（进程管理、存储管理、设备管理、文件管理、作业管理）
