# 法律法规和标准规范

## 考情分析

- 预计分值：选择题3~5分

## 核心考点

### 17.1 法律法规

#### 17.1.1 法与法律
- **法**：由国家制定、认可并保证实施，以权利义务为主要内容，由国家强制力保证实施的社会行为规范的总称
- **法律**：由国家行使立法权的机关依照立法程序制定和颁布的涉及国家重大问题的规范性文件
- 法律的效力仅低于宪法，其他一切行政法规和地方性法规都不得与法律相抵触
- **法的本质**：统治阶级意志的体现，由特定社会的物质生活条件决定
- **法的四大特征**：
  1. 法是调整人的行为或社会关系的规范
  2. 法是由国家制定或认可，并具有普遍约束力的社会规范
  3. 法是以国家强制力保证实施的社会规范
  4. 法是规定权利和义务的社会规范

#### 17.1.2 法律体系

**世界两大法系：**
1. **大陆法系（Civil Law/罗马法系/民法系）**：具有悠久的法典编纂传统，重视编写法典，具有详尽的成文法。崇尚法理上的逻辑推理，要求法官严格按照法条审判
2. **英美法系（Common Law/普通法系/海洋法系）**：又称不成文法系。司法审判原则上更**遵循先例**，即判例对其后的案件具有法律约束力。**判例法（Case Law）**不被实行大陆法系的国家承认

**中国特色社会主义法律体系（7大部门）：**
- 以**宪法为统帅**，以法律为主干，以行政法规、地方性法规为重要组成部分
1. **宪法相关法**：保障宪法实施和国家政权运作
2. **民法商法**：规范社会民事和商事活动
3. **行政法**：关于行政权授予、行使和监督
4. **经济法**：调整国家对经济活动实行干预、管理或调控所产生的社会经济关系
5. **社会法**：调整劳动关系、社会保障、社会福利和特殊群体权益保障
6. **刑法**：规定犯罪与刑罚
7. **诉讼与非诉讼程序法**：规范解决社会纠纷的诉讼与非诉讼活动

**法律体系中的法律法规层次：**
1. **法律**：全国人民代表大会及其常委会制定，国家主席签署主席令公布
2. **法律解释**：全国人大常委会做出，同法律具有同等效力
3. **行政法规**：国务院制定，总理签署国务院令公布，地位仅次于法律
4. **地方性法规、自治条例和单行条例**：省、自治区、直辖市人大及其常委会制定
5. **规章**：国务院各部委或地方政府制定，在本部门/本行政区域内有效

#### 17.1.3 法的效力
- **对象效力（对人的效力）**：中国公民在中国领域内一律适用中国法律；外国人和无国籍人在中国领域内，除法律另有规定外，适用中国法律
- **空间效力**：一国法律适用于该国主权范围所及的全部领域（领土、领水及底土和领空、驻外使馆、在外船舶及飞机）
- **时间效力**：
  - 生效时间：自公布之日起生效/法律规定具体生效时间/规定公布后符合一定条件时生效
  - 终止生效：明示的废止/默示的废止
  - **法的溯及力**：法律对其生效以前的事件和行为是否适用

#### 17.1.4 法律法规体系的效力层级（必考！）
- **纵向效力层级**：宪法 > 法律 > 行政法规 > 地方性法规 > 规章。上级机关制定的高于下级
- **横向效力层级**：同一机关制定，特别规定与一般规定不一致的，适用**特别规定**
- **时间序列效力层级**：同一机关制定，新的规定效力高于旧规定（**新法优于旧法**）

**特殊情况处理：**
- 法律之间新一般与旧特别不一致：由**全国人大常委会**裁决
- 地方性法规与部门规章不一致：由**国务院**提出意见。认为适用地方性法规→在该地方适用；认为适用部门规章→提请**全国人大常委会**裁决
- 部门规章之间/部门规章与地方政府规章之间不一致：由**国务院**裁决

#### 17.1.5 常用法律（8部，考试重点）

**1. 民法典（合同编）：**
- 2020年5月第十三届全国人大通过
- 合同是民事主体之间设立、变更、终止民事法律关系的协议
- 依法成立的合同，受法律保护，仅对当事人具有法律约束力
- 合同文本采用两种以上文字订立并约定具有同等效力的，对各文本使用的词句推定具有相同含义
- **信息化法律法规领域最重要的法律基础**

**2. 招标投标法：**
- 规范招标投标活动，调整在招标投标过程中产生的各种关系
- 有《招标投标法实施条例》作为执行补充

**3. 政府采购法：**
- 政府采购：各级国家机关、事业单位和团体组织，使用**财政性资金**采购依法制定的集中采购目录以内或采购限额标准以上的货物、工程和服务的行为
- 目的：规范政府采购行为，提高资金使用效益，维护国家利益和社会公共利益，促进廉政建设

**4. 专利法：**
- 2021年6月1日正式实施（第四次修正）
- 发明创造：**发明**（对产品、方法或其改进提出的新技术方案）、**实用新型**（对产品形状、构造提出的适于实用的新技术方案）、**外观设计**（对产品整体或局部的形状、图案结合做出的新设计）
- 发明专利权的期限为20年，实用新型专利权为10年，外观设计专利权为15年（需核实最新法规）

**5. 著作权法：**
- 2021年6月1日正式施行（第三次修正）
- 对著作权保护及其具体实施做出明确规定

**6. 商标法：**
- 国务院工商行政管理部门商标局主管全国商标注册和管理
- 注册商标：商品商标、服务商标、集体商标、证明商标
- 商标注册人享有商标专用权，受法律保护

**7. 网络安全法：**
- 2017年6月1日正式实施
- 我国**第一部全面规范网络空间安全管理**方面问题的基础性法律
- 明确了部门、企业、社会组织和个人的权利、义务和责任
- 适用于在中华人民共和国境内建设、运营、维护和使用网络

**8. 数据安全法：**
- 2021年9月1日正式实施
- 数据安全领域最高位阶的专门法
- 与网络安全法一起补充了《国家安全法》框架下的安全治理法律体系

### 17.2 标准规范

#### 17.2.1 标准和标准化
- **标准**：通过标准化活动，按照规定的程序经协商一致制定，为各种活动或其结果提供规则、指南或特性，供共同使用和重复使用的文件（GB/T 20000.1）
- **标准化**：为了在既定范围内获得最佳秩序，促进共同效益，对现实问题或潜在问题确立共同使用和重复使用的条款以及编制、发布和应用文件的活动

**主要标准化机构：**
- **ISO**：国际标准化组织，世界上最大、最有权威性的国际标准化专门机构
- **IEC**：国际电工委员会，世界最早的国际性电工标准化机构
- **ITU**：国际电信联盟，联合国专门机构
- **SAC**：国家标准化管理委员会（中国）
- **CITS**：全国信息技术标准化技术委员会（中国）

#### 17.2.2 标准分级与标准分类（必考！）

**标准五个级别：**
1. **国家标准**：需要在全国范围内统一的技术要求。由国务院标准化行政主管部门制定。代号**GB（强制性）**或**GB/T（推荐性）**
2. **行业标准**：没有推荐性国家标准但需要在某个行业范围内统一的技术要求。由国务院有关行政主管部门制定
3. **地方标准**：满足地方自然条件、风俗习惯等特殊技术要求。由省、自治区、直辖市标准化行政主管部门制定。代号**DB**
4. **团体标准**：依法成立的社会团体为满足市场和创新需要制定。代号**T**
5. **企业标准**：企业范围内需要协调统一的技术、管理和工作要求。代号**Q**

**标准类型：**
- **强制性标准**：保障人身健康和生命财产安全、国家安全、生态环境安全以及满足经济社会管理基本需要的技术要求。**必须执行**。代号**GB**
- **推荐性标准**：满足基础通用、与强制性标准配套、起引领作用等需要的技术要求。**国家鼓励采用**。代号**GB/T**
- 行业标准、地方标准是推荐性标准

#### 17.2.3 标准编号及名称
- **强制性国家标准**代号：**GB**；**推荐性国家标准**代号：**GB/T**；指导性技术文件代号：**GB/Z**；国家标准样品代号：**GSB**
- 国家标准的编号 = 国家标准代号 + 发布顺序号 + 年份号
- **行业标准代号**（IT相关）：电子（SJ）、通信（YD）、机械（JB）
- 地方标准编号：DB + 行政区划代码 + 顺序号 + 年代号
- 标准名称三元素：引导元素（可选）+ **主体元素（必备）**+ 补充元素（可选）

#### 17.2.4 标准有效期
- **国家标准**：一般**5年**复审一次（有效期一般为5年）
- **行业标准、地方标准**：复审周期一般不超过5年
- **企业标准**：复审周期一般不超过**3年**

#### 17.2.5 信息系统集成常用标准
**基础标准：**
- GB/T 11457《信息技术 软件工程术语》：1859个软件工程领域中文术语
- GB/T 1526《数据流程图、程序流程图等符号及规定》
- GB/T 14085《计算机系统配置图符号及约定》

**生存周期管理标准：**
- GB/T 8566《软件生存周期过程》
- GB/T 22032《系统与软件工程 系统生存周期过程》

**质量与测试标准：**
- GB/T 15532《计算机软件测试规范》
- GB/T 25000系列《系统与软件质量要求和评价（SQuaRE）》

**文档管理标准：**
- GB/T 8567《计算机软件文档编制规范》
- GB/T 9385《计算机软件测试文档编制规范》
- GB/T 16680《用户文档的管理者要求》

## 记忆要点
1. **效力层级口诀**：宪法最最高，法律次之，行政法规老三，地方性法规老四，规章最末
2. **法系区别**：大陆法→成文法/法典；英美法→判例法/先例
3. **标准五级**：国标(GB)→行标(SJ等)→地标(DB)→团标(T)→企标(Q)
4. **强制性vs推荐性**：GB必须执行，GB/T鼓励采用
5. **标准有效期**：国标/行标/地标5年，企标3年
6. **合同三大原则**：依法成立受保护、仅对当事人有约束力、诚信原则解释
7. **政府采购**：使用财政性资金，采购目录内或限额以上

## 常见题型
1. **选择题**：中国特色社会主义法律体系以什么为统帅？
   - 答：A. 宪法
2. **选择题**：调整国家对经济活动实行干预、管理或调控所产生的社会经济关系的法律规范是？
   - 答：B. 经济法
3. **选择题**：由国务院各部委制定的，仅在本部门权限范围内有效的是？
   - 答：D. 规章
4. **选择题**：推荐性国家标准代号是？
   - 答：A. GB/T
5. **选择题**：国家标准的有效期一般是？
   - 答：B. 5年
6. **选择题**：根据《标准化法》，行业标准由谁制定？
   - 答：A. 国务院有关行政主管部门
7. **选择题**：为在既定范围内获得最佳秩序，确立共同使用和重复使用的条款的活动是？
   - 答：D. 标准化
