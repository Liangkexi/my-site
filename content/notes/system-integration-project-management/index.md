## 考试大纲与导读

### 考试概述

系统集成项目管理工程师是全国计算机技术与软件专业技术资格（水平）考试（简称"软考"）的中级资格考试，自2005年开考以来，已培养了大批项目管理人才。该岗位是信息化建设和数字化转型过程中不可或缺的重要岗位。

### 本书定位

本书由全国计算机专业技术资格考试办公室组织编写，依据2023年审定通过的新版考试大纲，是参加系统集成项目管理工程师考试的必读教材。第3版教程在旧版基础上进行了较大幅度修订，增强了信息化发展、信息技术、信息技术服务、信息系统集成、信息安全工程等方面的知识要求，并丰富完善了项目管理知识体系。

### 全书知识框架

全书共18章，可分为五大模块：

1. **信息技术基础（第1～8章）**：信息化发展 → 信息技术发展 → 信息技术服务 → 信息系统架构 → 软件工程 → 数据工程 → 软硬件系统集成 → 信息安全工程
2. **项目管理概论（第9章）**：PMBOK发展、项目基本要素、项目经理角色、项目生命周期、立项管理、项目管理过程组与知识领域
3. **项目管理过程组（第10～14章）**：启动 → 规划 → 执行 → 监控 → 收尾
4. **组织保障与监理（第15～16章）**：信息/文档管理、配置管理、变更管理；监理基础知识
5. **法规与职业道德（第17～18章）**：法律法规与标准规范、职业道德规范

### 备考建议

- 第1～8章为信息技术基础，约占考试30%，以选择题为主
- 第9～14章为项目管理核心，约占考试50%，涵盖选择题、案例分析
- 第15～18章为保障与法规，约占考试20%
- 重点突破第9～11章（项目管理概论+规划过程组），这三大章是案例分析的核心
- 每章末提供练习题，建议刷完并对照解析
